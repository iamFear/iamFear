## Sobre mí

Soy Daniel Burgoa, CEO de **Astodev**. Llevo más de cinco años diseñando sistemas y liderando operaciones tecnológicas y logísticas, con una convicción: **el software debe ser una ventaja competitiva para el negocio**.

Mi trabajo conecta desarrollo de software, análisis de datos y gestión de operaciones. Me involucro desde la arquitectura técnica hasta las decisiones que influyen en producto, precios, inventario y conversión, buscando que cada solución responda a una necesidad concreta.

Trabajo con empresas que buscan un socio tecnológico capaz de entender su operación, definir prioridades y acompañar la ejecución.

## Proyectos destacados

### [Astodev](https://github.com/iamFear/astodev)

Sitio corporativo que organiza la oferta de servicios, precios y canales de contacto de Astodev. Incluye componentes reutilizables y un formulario preparado para Netlify Forms, con campo de protección contra spam y página de confirmación.

**Enfoque:** conectar la presentación de servicios con el contacto comercial.  
**Tecnologías:** Astro · CSS · Netlify Forms.

### [WellView Care](https://github.com/iamFear/wellview-care)

Experiencia web para presentar servicios de salud y orientar al visitante hacia la solicitud de una cita. Incluye un selector de sede, tipo de atención y condición de paciente, con redirección al sistema externo de agendamiento de la sede elegida.

**Enfoque:** navegación clara, interacciones de interfaz y respeto por las preferencias de movimiento reducido.  
**Tecnologías:** Astro · TypeScript · CSS.

### [Eficiencia Energética Aplicada](https://github.com/iamFear/eficiencia-energetica-aplicada)

Sitio que estructura un portafolio de soluciones energéticas y proyectos por categoría. Utiliza datos tipados y páginas generadas por solución y proyecto para organizar información técnica en una experiencia navegable.

**Enfoque:** convertir documentación técnica en contenido útil para explorar servicios y proyectos.  
**Tecnologías:** Astro · TypeScript · CSS.

### [FinanzasYa](https://github.com/iamFear/FinanzasYa)

Herramienta web que calcula una referencia de presupuesto diario a partir de un monto disponible y los días restantes del mes. Incluye procesamiento de entradas numéricas con separadores decimales y actualización de resultados en la interfaz.

**Enfoque:** traducir una necesidad cotidiana en una interacción sencilla.  
**Tecnologías:** JavaScript · HTML · CSS.
